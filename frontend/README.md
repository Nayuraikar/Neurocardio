# NeuroCardio frontend

React, TypeScript and Vite. Setup, versions and run commands are in the [project README](../README.md).

```sh
npm ci           # install the locked versions
npm run dev      # UI on http://localhost:5173, proxies /api to NEUROCARDIO_API (default http://127.0.0.1:8000)
npm run lint
npm run build    # type check and production build
npm run e2e      # see e2e/README.md
```
